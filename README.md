# Assistente-IA

## Executar localmente com o XAMPP

1. Inicie o Apache pelo painel do XAMPP.
2. No terminal, na pasta do projeto, execute `node server.js` e mantenha-o aberto.
3. Acesse `http://localhost/Assistente-IA-Rocki-e-poses/public/`.

O Apache serve a página; o servidor Node, na porta `3333`, lê o `.env` e atende ao chat. Os dois precisam estar em execução.
